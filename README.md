# Черновик сайта открытого письма

Статическая одностраничная страница для GitHub Pages, без сборки и зависимостей. Композиция вдохновлена предоставленным референсом: чёрная шапка, серый фон, красный акцент, письмо и список в три колонки. Чужие тексты, подписи, фотографии и скрипты Tilda не перенесены.

## Запуск

Откройте index.html в браузере. Для публикации: Settings → Pages → Source: GitHub Actions. Существующий workflow в .github этим коммитом не изменяется. Проверьте результат запуска на вкладке Actions.

## Редактирование

Весь макет находится в index.html: CSS в style, содержание в body, интерактивность в script. Замените текст в квадратных скобках. Цвета задаются в :root. Адаптация для телефона включена. Внешние шрифты, изображения, аналитика и сторонние библиотеки не подключены.

## Ограничения черновика

- Форма отключена; данные не отправляются и не сохраняются приложением.
- Кнопка демонстрации только показывает сообщение.
- Все шесть записей списка явно демонстрационные. Счётчик реальных подписей равен нулю.
- Автоматическое обновление общего списка пока не реализовано: нужен отдельный сервис.
- Не храните реальные подписи, email, токены или резервные копии в репозитории.
- noindex,nofollow — просьба поисковым системам, а не контроль доступа. Опубликованный черновик доступен публично.
- Отсутствие аналитики в коде не исключает обработку технических данных хостингом.

## Перед реальным запуском

Утвердить текст и адресата, фотографии и права на них, сведения об операторе, правовые основания и документы, отдельное согласие на распространение, требования локализации, сроки хранения, отзыв, подтверждение подписей и защиту сервиса. Проверить интерфейс на телефоне и компьютере и клавиатурную навигацию. Данный макет не является юридическим заключением или готовой системой сбора подписей.
